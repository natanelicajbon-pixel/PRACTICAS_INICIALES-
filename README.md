## Descripción

Este repositorio contiene la documentación correspondiente al **Informe No. 1** del curso de Organización Computacional, en el cual se desarrolla el procedimiento de mantenimiento preventivo realizado a una computadora de escritorio.

El contenido incluye:

- 📘 Manual Técnico
- 📑 Trifoliar informativo
- 🎥 Video demostrativo
- 🤖 Prompts utilizados para la generación de contenido mediante Inteligencia Artificial

---

## Objetivos

- Identificar los principales componentes internos de una computadora.
- Aplicar procedimientos adecuados de mantenimiento preventivo.
- Sustituir correctamente la pasta térmica del procesador.
- Documentar el proceso técnico realizado.
